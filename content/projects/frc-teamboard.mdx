## Problem

Running a build season means dozens of small tasks across subteams, a pit to set up at every event,
and a match schedule that changes under you. That information lived in group chats and whiteboards.

## Approach

A full-stack app with authenticated team accounts: drag-and-drop task boards per subteam, a pit map
with the robot's location at each event, and live match queueing pulled from the FRC Nexus API so
the drive team always knows how long until they're on. Postgres via Prisma, Dockerized for local
development, continuous deployment on Vercel.
