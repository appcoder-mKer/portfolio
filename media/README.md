# Media

Pictures for the site go here.

```
media/profile.jpg                    your photo in the header (see the PHOTO note in index.html)
media/og.png                         the preview picture shown when the site link is shared
media/projects/<project>/cover.jpg   picture in a project's box on the home page
media/projects/<project>/01.jpg …    pictures inside a project page
```

Guidelines
- Landscape 16:10 for covers (e.g. 1600×1000). JPEG or WebP, under ~400 KB each.
- Always write real `alt` text (what is in the picture, not "image").
- `<project>` is the project's file name in `work/` without `.html`.
